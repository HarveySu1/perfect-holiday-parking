# DESIGN.md｜车记得 · 复赛汇报

> 风格路由：产品提案 / 比赛评审场景 → 不命中学术 / 商务咨询 / 红金政务预设 → **通用设计原则（universal-only）**。
> 用户显式指令：**简单明了**。本文即本项目设计宪法。

## 1. 画布与全局母版（具体 px）

- **画布**：1280 × 720 px。
- **页面 padding**：上 20 / 下 20 / 左 64 / 右 64（安全区 1152 × 680）。
- **母版三区**（P2–P9、B1–B3 内容页严格一致；P1 封面自定义；P9 结束页保留简化页脚）：

| 母版区 | 垂直位置 | 高度 | 内容规则 |
| :--- | :--- | :--- | :--- |
| **A · 标题块** | 0–120px | 120px | kicker 13px/600/letterSpacing 2（主色，y≈24）+ 主标题 30px bold（y≈48，lineHeight 1.25）；标题块右侧禁放任何装饰图 |
| **B · 内容区** | 120–660px | 540px | 一切正文、卡片、表格、配图；禁止挤占 A/C |
| **C · 页脚条** | 660–720px | 60px | 左：FAIcon `car`（18px，主色）+「车记得 · 完美金鹰假日商圈 AI 大赛」13px #5C6470；右：页码 `NN / 12`（13px，#5C6470，NN 主色 bold） |

- 内容页标题位置、页码位置全篇稳定，禁止逐页发挥。

## 2. 颜色系统

**色彩池（4 hex，全篇仅允许这 4 个彩色 hex）**：

| 角色 | hex | 用途 |
| :--- | :--- | :--- |
| 主色（蓝） | `#2456E6` | 标题强调、左侧色块、结构线、表头、页码数字、L3 徽标 |
| 辅色（绿） | `#0FA958` | 「复用已有能力 / 通过项 ✔ / 落地阶段」语义 |
| 强调（琥珀） | `#F5A623` | AI 层标记、CTA、诚实标注、锚点数字描边——只出现在焦点元素 |
| 背景 | `#FFFFFF` | 页面底色 |

**中性阶（不计入色彩池）**：`#16181D` 文本主 / `#5C6470` 文本次 / `#E5E8EF` 边框分隔 / `#F5F7FB` 浅底卡片。

**色彩面积分配**：

| 角色 | 面积占比 | 说明 |
| :--- | :--- | :--- |
| 主色 | ≤ 60% | 大面积仅出现在 P1 封面（深图+蒙版）与左侧色块页（P2/P5/B1/B3） |
| 辅色 | ≤ 30% | P7 阶段卡主导（与蓝主导页显著不同）；其余页仅 ✔/复用标签 |
| 强调色 | Supporting ≤ 5%；**Hero 页 15–20%** | P5（AI 标记+圆场条）、P1（slogan 强调线） |
| 中性色 | 剩余 | 文本、页脚、边框、浅底 |

**渐变与半透明方案**：
- P1 封面：底图上叠 `linear-gradient(105deg, rgba(8,12,24,0.80) 0%, rgba(8,12,24,0.45) 55%, rgba(8,12,24,0.12) 100%)`，白字骑左。
- 浅底卡片：`background: '#F5F7FB'` + `border: '1px solid #E5E8EF'` + `boxShadow: '0 4px 20px rgba(22,24,29,0.06)'`。
- 主色标签：底 `rgba(36,86,230,0.08)` + 边 `rgba(36,86,230,0.25)`。
- AI 元素（强调）：底 `rgba(245,166,35,0.12)` + 左边框 `3px solid #F5A623`。
- 复用/已有（辅色）：底 `rgba(15,169,88,0.10)` + 边 `rgba(15,169,88,0.35)`。
- 装饰：B 区角落绝对定位主色圆，`opacity: 0.06–0.10`，不占安全区、不影响内容布局。

## 4. 信息密度门禁

- 内容页正文合计 ≥ 180 字；常规页留白 ≤ 35%（Hero/结束页可到 40%，留白围绕锚点）。
- 容器填充率 ≥ 85%：卡片尾部元素（标签条/引文条）用 `marginTop: 'auto'` 钉底；同行兄弟卡「标题块/正文块/尾条」三段 y 轴等高对齐（差 > 16px 返工）。
- 每页 ≥ 1 个视觉锚点（≥ 44px 元素或 ≥ 40% B 区面积的图）；锚点周围 ≥ 40px 呼吸空间。
- 单页图片 ≤ 3 张，图片总面积 ≤ B 区 60%。

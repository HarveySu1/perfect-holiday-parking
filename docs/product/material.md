# Material: 车记得·复赛PPT

> 来源：工作空间已有材料（v3方案书、调研记录、研究稿、demo v4.1）。无web搜索，材料已齐。

## 1. Overview
- 车记得 = 给完美金鹰·假日商圈已有停车系统补一层"决策服务"
- 不重做地图/识别/导航，只在"设为终点"前插一步决策
- 三个增量：目的地选车位 / 电梯厅选梯 / 充电桩导航空闲桩

## 2. Background
- 完美金鹰广场与假日广场2026-08-18打通，体量62万㎡、年客流超3000万、会员超80万
- 大赛：金鹰亚洲×ATOX，赛道二（商圈服务·用户体验）
- 复赛提交PPT+代码+视频，截止10/15 12:00，审核10/8-10/18

## 3. Key Info
- AI三层用点：LLM意图解析（入口）/ 多模态OCR（兜底）/ 生成式解释（输出）
- 实时决策用确定性算法——工程判断非能力不足
- 一期石岐万象汇灰度，零硬件零系统改造

## 4. Evidence
- 深圳三场实地调研（前海万象汇/前海卓越/万象天地），6张截图存assets/research-sz-20261014/
- 万象天地数据最齐但也未做"目的地选车位"——核心实证
- demo v4.1可演AI入口（说一句话→解析→推荐）

## 5. Analysis
- 竞品矩阵：ETCP/华为/云快充/主办方系统 vs 车记得
- 三家全把智能花在"找回车"，无人做"停车前选车位"
